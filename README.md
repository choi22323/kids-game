# 받아쓰기 교실 — 우리들의 즐거운 한글 교실

**서구종합사회복지관 성인문해교실 스마트 칠판 받아쓰기 프로그램 (프로토타입)**

컴퓨터가 문장을 소리 내어 읽어 주면, 어르신이 스마트 칠판의 받아쓰기 칸에 손가락이나 펜으로 받아 씁니다.
다시 듣고 싶으면 [다시 듣기]를 누르면 되고, 다 쓰면 바로 아래에 같은 모양의 정답 칸이 나와 비교해 볼 수 있습니다. 인터넷 연결이나 설치가 필요 없습니다.

> 현재 상태: **받아쓰기 프로토타입** — **애국가 1절(10문장 한 묶음)**, **4학년 2학기 '2. 우리말 우리글' 86~95번(번호마다 한 문제씩, 10문제)**.
> (86~95번은 급수표 사진에서 옮겨 적었으므로 원문과 한 번 대조해 주세요. 특히 87번 "혀가 윗잇몸에 닿는 모양")
> 이전의 4종 활동(따라쓰기·초성·짝짓기·빈칸) 버전은 git 기록(커밋 `e346351`)에 남아 있습니다.

## 1. 사용 방법
1. 폴더의 `index.html`을 **Chrome 또는 Edge**로 엽니다. (칠판에서는 F11 전체 화면)
2. 홈에서 **[소리 시험]** 을 눌러 한국어 읽어 주기 음성이 나오는지 확인합니다.
3. 문장 묶음의 **[시작하기]**, 또는 번호 버튼(**86번 ~ 95번**)을 누르면 그 한 문제만 받아 씁니다. 다 쓰면 **[다음 문제: 87번 ▶]** 으로 이어 갈 수 있습니다.
   - **🔊 다시 듣기**: 몇 번이든 다시 듣기 (키보드 `R`)
   - **🐢 천천히 한 글자씩**: "동 · 해 … 물 · 과"처럼 한 글자씩 또박또박 끊어 읽고(띄어쓰기는 더 길게 쉼), 읽는 글자의 칸에 불이 들어옵니다
   - **지우기** / **다 썼어요** / **건너뛰기**
4. [다 썼어요]를 누르면 내가 쓴 칸 **바로 아래에 같은 크기·같은 배치의 정답 칸**이 나옵니다. 칸끼리 비교해 스스로(또는 강사님과 함께) 확인합니다. 다시 쓰려면 [다시 써 보기].
5. [나가기]는 2초 동안 길게 눌러야 동작합니다(실수 방지).

## 휴대폰·태블릿에서 쓰기
- 휴대폰(세로·가로)과 태블릿 화면에 맞춰 버튼·글자 크기와 칸 배치가 바뀝니다. 칸은 화면에 맞게 여러 줄로 나뉘어 가장 크게 보입니다.
- 휴대폰 가로처럼 높이가 낮아 정답 칸을 아래에 둘 자리가 없으면, **내가 쓴 칸 안에 정답을 흐리게 겹쳐** 보여 주고 아래에 정답 문장을 한 줄로 보여 줍니다.
- 휴대폰에서 열려면 이 폴더를 휴대폰으로 옮기거나 웹 주소(내부망·웹 호스팅)로 열어야 합니다. 휴대폰 브라우저에서 파일을 직접 여는 방법은 기기마다 달라 확인이 필요합니다.
- 자료(기록·설정)는 기기마다 따로 저장됩니다.

## 2. 설정 (상단 ⚙ 설정)
| 항목 | 내용 | 기본값 |
|---|---|---|
| 칸 안 흐린 글씨 | 없음 / 쓸 때부터 보기(따라쓰기처럼) | **없음** |
| 목소리 | 이 컴퓨터에 설치된 한국어 목소리 중 선택 ([들어 보기]) | 자동(가장 친근한 목소리) |
| 목소리 높낮이 | 낮고 차분하게 ~ 밝게 | 조금 밝게(110%) |
| 읽기 속도 | 아주 천천히 ~ 조금 빠르게 | 천천히(85%) |
| 글자 크기 | 보통 / 크게 / 아주 크게 | 보통 |
| 효과음·애니메이션·필기 굵기·관리자 PIN | | |

## 3. 정답 확인 방식
- 자동 채점은 하지 않습니다. (손글씨 자동 판정은 정확도가 낮아 없앴습니다 — 이전 구현은 커밋 `23f16ac`에 있음)
- [다 썼어요]를 누르면 내가 쓴 칸 아래에 **똑같은 받아쓰기 칸으로 정답**을 보여 줍니다. 띄어쓰기 칸과 문장부호(. ?) 칸도 같은 자리에 나오므로 띄어쓰기·문장부호까지 칸마다 비교할 수 있습니다.

## 4. 읽어 주기 음성
- **자동 선택 순서**: 인터넷 없이 되는 음성 → 그중 '자연스러운(Natural)' 신경망 음성 → 부드러운 목소리(선희·유나·서연 등) 순으로 고릅니다. 실제로 어떤 목소리가 있는지는 컴퓨터마다 다릅니다(확인 필요).
- 설정 → 읽어 주기·소리에서 목소리를 직접 고르고 [들어 보기]로 비교할 수 있습니다. '인터넷 필요' 표시가 있는 목소리는 오프라인 교실에서 소리가 나지 않을 수 있습니다.
- 브라우저에 내장된 음성 기능(speechSynthesis)만 씁니다. 외부 음성 서비스는 쓰지 않습니다.
- **인터넷 없이 읽으려면 컴퓨터에 한국어 음성이 설치되어 있어야 합니다.** (Windows: 설정 → 시간 및 언어 → 언어 → 한국어 → 음성 — 기관 PC에서 확인 필요)
- 음성이 없으면 화면에 안내가 나오고, 강사님이 **[강사용 문장 보기]** 로 문장을 보고 직접 읽어 주시면 됩니다.

## 5. 개인정보·저장
- 어르신 성함 등 개인정보를 입력하는 칸이 없습니다. 손글씨는 화면에만 그리고 **저장하지 않습니다.**
- 받아쓰기 결과(몇 문장을 맞혔는지)만 이 PC 브라우저(IndexedDB)에 남습니다. 다른 PC·브라우저와 자동으로 공유되지 않고 암호화되지 않습니다.

## 6. 개발자 점검
- `tests/test.html` — 단위 테스트 28건 (브라우저로 열기, 또는 `node tests/e2e/run-unit.js`)

- `node tests/e2e/mobile-check.js` — 휴대폰·태블릿 화면 점검
