# 받아쓰기 교실 — 우리들의 즐거운 한글 교실

**서구종합사회복지관 성인문해교실 스마트 칠판 받아쓰기 프로그램 (프로토타입)**

컴퓨터가 문장을 소리 내어 읽어 주면, 어르신이 스마트 칠판의 받아쓰기 칸에 손가락이나 펜으로 받아 씁니다.
다시 듣고 싶으면 [다시 듣기]를 누르면 되고, 다 쓰면 칸마다 맞았는지 표시됩니다. 인터넷 연결이나 설치가 필요 없습니다.

> 현재 상태: **받아쓰기 프로토타입** — 시험용 문장 묶음은 **애국가 1절(10문장)** 하나입니다.
> 이전의 4종 활동(따라쓰기·초성·짝짓기·빈칸) 버전은 git 기록(커밋 `e346351`)에 남아 있습니다.

## 1. 사용 방법
1. 폴더의 `index.html`을 **Chrome 또는 Edge**로 엽니다. (칠판에서는 F11 전체 화면)
2. 홈에서 **[소리 시험]** 을 눌러 한국어 읽어 주기 음성이 나오는지 확인합니다.
3. 문장 묶음의 **[시작하기]** → 문장을 들려 드리면 칸에 받아 씁니다.
   - **🔊 다시 듣기**: 몇 번이든 다시 듣기 (키보드 `R`) · **🐢 천천히 듣기**: 더 느리게
   - **지우기** / **다 썼어요** / **건너뛰기**
4. [다 썼어요]를 누르면 칸마다 **✔(맞음)** 또는 **?(다시 확인)** 가 표시되고, 아래에 정답이 나옵니다. 틀린 글자에는 물결 밑줄이 그어집니다.
5. 강사님은 **[맞음으로 바꾸기 / 틀림으로 바꾸기]** 로 판정을 고칠 수 있습니다.
6. [나가기]는 2초 동안 길게 눌러야 동작합니다(실수 방지).

## 2. 설정 (상단 ⚙ 설정)
| 항목 | 내용 | 기본값 |
|---|---|---|
| 칸 안 흐린 글씨 | 없음 / 정답 확인 때만 / 쓸 때부터 보기(따라쓰기처럼) | **없음** |
| 정답 판정 | 자동 판정 켜기·끄기, 엄격하게 / 보통 | 켜짐, 엄격하게 |
| 읽기 속도 | 아주 천천히 ~ 조금 빠르게 | 천천히(85%) |
| 글자 크기 | 보통 / 크게 / 아주 크게 | 보통 |
| 효과음·애니메이션·필기 굵기·관리자 PIN | | |

## 3. 정답 판정은 어떻게 하나요? (꼭 읽어 주세요)
- 인터넷·외부 프로그램 없이, 칸 안 글씨 모양을 **정답 글자**와 **헷갈리기 쉬운 글자 약 50개**(초성·중성·받침을 하나씩 바꾼 글자)와 비교합니다. 정답 글자가 가장 비슷할 때만 맞음으로 봅니다.
- 빈 칸, 띄어쓰기 칸에 쓴 글씨는 틀림으로 봅니다. 숫자·문장부호는 판정하지 않습니다.
- 개발 PC 시험(글꼴로 흉내 낸 손글씨) 결과: **엄격하게** ≈ 바르게 쓴 글자 85% 인정, 틀린 글자 95% 구별 / **보통** ≈ 93% 인정, 87% 구별.
- 실제 어르신 손글씨에서는 결과가 다를 수 있습니다. **보조 판정**이므로 강사님이 확인하고 필요하면 판정을 바꿔 주세요. (현장 시범 후 기준값 조정 필요)

## 4. 읽어 주기 음성
- 브라우저에 내장된 음성 기능(speechSynthesis)만 씁니다. 외부 음성 서비스는 쓰지 않습니다.
- **인터넷 없이 읽으려면 컴퓨터에 한국어 음성이 설치되어 있어야 합니다.** (Windows: 설정 → 시간 및 언어 → 언어 → 한국어 → 음성 — 기관 PC에서 확인 필요)
- 음성이 없으면 화면에 안내가 나오고, 강사님이 **[강사용 문장 보기]** 로 문장을 보고 직접 읽어 주시면 됩니다.

## 5. 개인정보·저장
- 어르신 성함 등 개인정보를 입력하는 칸이 없습니다. 손글씨는 화면에만 그리고 **저장하지 않습니다.**
- 받아쓰기 결과(몇 문장을 맞혔는지)만 이 PC 브라우저(IndexedDB)에 남습니다. 다른 PC·브라우저와 자동으로 공유되지 않고 암호화되지 않습니다.

## 6. 개발자 점검
- `tests/test.html` — 단위 테스트 23건 (브라우저로 열기, 또는 `node tests/e2e/run-unit.js`)
- `node tests/e2e/dictation.js` — 받아쓰기 흐름(읽어 주기·다시 듣기·기록)
- `node tests/e2e/judge.js` — 정답 판정(바르게 / 두 글자 틀리게 / 낙서 / 강사 판정)
- `node tests/e2e/layout-check.js` — 전 화면 100vh·크기 규칙 (Playwright 필요, 배포물 아님)
