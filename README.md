# 우리들의 즐거운 한글 교실

**서구종합사회복지관 성인문해교실 스마트 칠판 체험 프로그램**

대형 스마트 칠판(터치 모니터·스마트 TV) 앞에서 어르신들이 손가락이나 터치펜으로 직접 글씨를 따라 쓰고, 낱말 퀴즈를 풀며 한글을 익히는 **오프라인 웹 프로그램**입니다. 인터넷 연결, 설치 프로그램, 회원 가입이 필요 없습니다.

> 현재 상태: **설계 단계(v0.1.0)** — 설계 문서만 작성되어 있으며 기능 코드는 아직 없습니다. 아래 실행·사용법은 구현 목표 기준입니다.

---

## 1. 누가 쓰나요?

| 사용자 | 하는 일 |
|---|---|
| 문해교육 강사·사회복지사 (1명) | 수업 주제·수준에 맞는 문제 세트 준비, 수업 진행, 학습지 출력, 자료 백업 |
| 성인문해교실 어르신 (10명 내외) | 칠판 앞에 나와 글씨 쓰기·퀴즈 체험 (계정·개인정보 입력 없음) |

## 2. 주요 기능

**4가지 체험 활동**
1. **깍두기 칸 글씨 따라쓰기** — 흐린 글씨 위를 손가락·펜으로 따라 쓰기
2. **초성 보고 낱말 맞히기** — "ㅂㅊ"를 보고 "배추" 고르기
3. **그림과 낱말 선 긋기** — 그림과 낱말을 선으로 잇기
4. **생활 속 빈칸 문장 완성** — "시장에서 (　)를 샀어요."

**수업 운영**
- 내장 문제 세트 **15개**(가족·건강·병원·시장·경제·사계절·교통 × 초급·중급·고급)
- 강사가 직접 문제 세트를 만들거나 내장 세트를 복제해 고치기, 그림 등록
- 수업 계획(날짜·활동 순서) 작성과 전체 화면 수업 모드
- 정답 시 칭찬 효과음·별 애니메이션(인터넷 없이 동작), 별 1~3개 자동 계산
- 수업 후 **A4 복습 학습지** 인쇄 또는 PDF 저장
- 수업 운영 통계(어르신 개인별 정보 없음)
- 글자 크기 3단계, 소리·애니메이션 설정, (선택) 관리자 PIN
- 백업 파일 저장·복원, 문제 세트 파일 공유

## 3. 준비물

| 항목 | 권장 |
|---|---|
| PC | 기관 PC (Windows 가정, 확인 필요) |
| 브라우저 | **Chrome 또는 Edge 최신 버전** |
| 화면 | 16:9 가로 화면, 1920×1080 권장(최소 1280×720) |
| 칠판 연결 | PC를 HDMI로 칠판에 연결하고 터치(USB)를 함께 연결하는 방식 권장. 칠판 내장 브라우저에서 직접 실행 가능 여부는 확인 필요 |
| 프린터 | A4 (흑백 가능) |
| 백업 저장 장치 | 기관 USB 또는 기관 공유 폴더 |

## 4. 설치·실행

### 4.1 설치 (폴더 복사)
1. 배포 폴더 전체(예: `hangul-classroom/`)를 기관 PC의 고정 위치에 복사합니다.
   - 예: `C:\한글교실\` — **한 번 정한 위치는 바꾸지 마세요.** 위치를 바꾸면 저장된 자료가 보이지 않을 수 있습니다(바꿔야 하면 먼저 백업하세요).
2. 별도 설치 과정은 없습니다.

### 4.2 실행
1. 폴더 안의 `index.html`을 **Chrome 또는 Edge로** 엽니다.
   - 파일을 마우스 오른쪽 버튼 → 연결 프로그램 → Chrome/Edge
2. 처음 실행하면 "수업 자료를 준비하고 있습니다" 화면 후 홈이 나타납니다.
3. 칠판에서 수업할 때는 **F11**(전체 화면)을 누르거나, 수업 시작 시 나오는 전체 화면 요청을 허용하세요.
4. (선택) 바탕화면 바로가기: Chrome 주소창의 파일 주소를 바로가기로 만들거나, 아래처럼 키오스크 모드로 실행할 수 있습니다. 경로는 실제 설치 위치에 맞게 바꾸세요.

```bash
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "file:///C:/한글교실/index.html"
```

> 키오스크 모드를 끝내려면 `Alt + F4`를 누릅니다.

### 4.3 중요: 실행 방법을 하나로 고정하세요
- 브라우저 저장소는 **여는 방법마다 따로** 저장됩니다. `index.html`을 직접 열었을 때와, 로컬 서버(`http://localhost…`)로 열었을 때의 자료는 서로 보이지 않습니다.
- Chrome에서 만든 자료는 Edge에서 보이지 않습니다. 브라우저도 하나로 정하세요.

### 4.4 개발자용
- 빌드 과정 없음. 파일을 고치고 브라우저를 새로고침하면 됩니다.
- 테스트: `tests/test.html`을 브라우저로 열면 단위 테스트가 실행됩니다.
- 개발 규칙은 `CLAUDE.md`, 단계별 계획은 `DEVELOPMENT_PLAN.md`를 보세요.

## 5. 사용법

### 5.1 수업 전 준비
1. **홈 → 관리자 설정 → 문제 세트**에서 주제와 수준을 골라 내장 세트를 확인합니다.
2. 우리 반에 맞게 바꾸려면 **[복제]** 후 낱말·문장을 고칩니다. (내장 세트는 직접 고칠 수 없습니다.)
3. 필요하면 **그림 자료**에 직접 그린 그림이나 사용 허락을 받은 그림을 등록합니다.
   - 어르신 얼굴 사진 등 사람이 알아볼 수 있는 사진은 등록하지 마세요.
4. **수업 계획 → 새 계획**에서 날짜, 주제, 수준, 활동 순서를 정해 저장합니다.
5. **백업 파일 저장**을 눌러 USB에 저장해 둡니다.

### 5.2 수업 중 (스마트 칠판)
1. 홈의 **오늘 수업 → [수업 시작]** (계획 없이 하려면 **[빠른 시작]**).
2. 어르신이 앞으로 나와 화면을 직접 터치하거나 펜으로 씁니다.
   - 따라쓰기: 다 쓰면 **[다 썼어요]**, 다시 쓰려면 **[지우기]**
   - 퀴즈: 보기를 누르면 바로 칭찬 소리와 별이 나옵니다. 틀려도 힌트와 함께 다시 할 수 있습니다.
3. 상단 **[가+]** 로 글자를 키우고, **[소리]** 로 효과음을 켜고 끕니다.
4. 강사용 키보드 단축키: `→` 다음, `←` 이전, `M` 소리, `+`/`-` 글자 크기
5. 수업 모드를 나가려면 **[나가기]를 2초 동안 길게** 누릅니다(PIN 설정 시 PIN 입력).

### 5.3 수업 후
1. 수업 마무리 화면에서 **[학습지 만들기]** 를 누릅니다.
2. 넣을 항목(따라쓰기·초성·빈칸·선잇기)과 글자 크기를 고르고 **[인쇄하기 / PDF로 저장]** 을 누릅니다.
   - PDF 파일로 저장하려면 인쇄 창의 "대상"을 **"PDF로 저장"** 으로 바꾸세요.
3. 출력한 학습지를 어르신들께 나눠 드립니다.
4. 자료를 고쳤다면 **백업**해 두세요.

## 6. 데이터 저장과 백업 — 꼭 읽어 주세요

### 6.1 자료는 어디에 저장되나요?
- 모든 자료는 **이 PC의 이 브라우저 안(IndexedDB)** 에만 저장됩니다. 인터넷이나 서버로 전송되지 않습니다.

### 6.2 알아 두셔야 할 한계
| 한계 | 의미 |
|---|---|
| 기기별 분리 | 다른 PC, 다른 브라우저, 시크릿 창에서는 자료가 보이지 않습니다 |
| 자동 동기화 없음 | 강사 PC와 칠판 PC 사이에 자동으로 옮겨지지 않습니다 |
| 암호화 없음 | 저장된 자료와 백업 파일은 암호화되지 않습니다. PC를 쓸 수 있는 사람은 내용을 볼 수 있습니다 |
| 사용자 권한 구분 없음 | 여러 강사별 계정·권한 관리 기능이 없습니다 |
| 사라질 수 있음 | 브라우저의 "인터넷 사용 기록 삭제(쿠키 및 사이트 데이터)", 브라우저 재설치, PC 초기화, 재부팅 시 초기화되는 보안 프로그램 등으로 **자료가 모두 지워질 수 있습니다** |

### 6.3 백업 방법
- **관리자 설정 → 백업·복원 → [백업 파일 저장]** → `한글교실_백업_날짜_시간.json` 파일이 저장됩니다.
- **권장 주기: 매주 1회, 그리고 자료를 고친 날.** 마지막 백업 후 7일이 지나면 홈에 알림이 나옵니다.
- 백업 파일은 기관 USB나 기관 공유 폴더에 보관하고, 개인 메신저·개인 이메일·외부 클라우드로 보내지 마세요.

### 6.4 복원 방법
1. **[백업에서 복원]** → 백업 파일 선택
2. 미리보기에서 자료 건수와 백업 날짜를 확인
3. **전체 교체**(지금 자료를 백업 내용으로 바꿈) 또는 **병합**(지금 자료에 더함) 선택
4. 복원 직전 지금 자료를 안전 백업으로 저장할지 묻습니다 — 저장을 권장합니다.
- 손상되었거나 다른 프로그램의 파일은 복원되지 않으며, 이 경우 기존 자료는 그대로 유지됩니다.

### 6.5 다른 반·다른 강사와 문제 세트 나누기
- **[세트 파일로 내보내기]** 로 필요한 세트만 파일로 만들어 전달하고, 받는 쪽은 **[세트 파일 가져오기]** 로 추가합니다.

## 7. 개인정보 보호 약속

- 이 프로그램에는 **어르신 성함·생년월일·연락처 등을 입력하는 칸이 없습니다.**
- 학습 기록은 "몇 문제를 맞혔는지" 같은 **활동 단위 결과**만 남고, 누가 했는지는 기록되지 않습니다.
- 손으로 쓴 글씨는 판정 후 저장하지 않습니다.
- 메모 등에 전화번호처럼 보이는 내용을 쓰면 경고가 나옵니다.
- 자세한 내용: `SECURITY.md`

## 8. 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 소리가 안 나요 | 화면을 한 번 터치한 뒤 다시 해 보세요(브라우저 정책상 첫 터치 후 소리가 납니다). 상단 [소리]와 PC·칠판 음량도 확인하세요 |
| 글씨가 끊겨요 | 브라우저를 최신으로 업데이트하고, 필기 굵기를 조금 키워 보세요. 계속되면 칠판 기종을 알려 주세요 |
| 화면이 잘려요 | 전체 화면(F11)을 켜고, 브라우저 확대/축소를 100%로(`Ctrl + 0`) 맞춰 주세요 |
| 자료가 사라졌어요 | 같은 브라우저·같은 위치의 `index.html`로 열었는지 확인하고, 아니면 최근 백업 파일로 복원하세요 |
| PIN을 잊었어요 | PIN 입력 화면의 [PIN을 잊으셨나요?] 안내를 따르세요. 자료는 지워지지 않습니다 |
